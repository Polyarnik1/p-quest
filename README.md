# Piano Quest 🎹

Веб-приложение для обучения игре на пианино. Один файл `index.html`, без библиотек и сборки, работает на телефоне и компьютере.

## Режимы

- **🎤 Учусь** — на экране нарисовано пианино, нужная клавиша подсвечивается. Приложение слушает микрофон, определяет ноту, которую ты сыграл на настоящем инструменте, и ждёт правильную.
- **🎵 Ритм** — ноты падают в темпе песни, за попадания начисляются очки и комбо.
- **👀 Демо** — приложение само играет мелодию и показывает, куда нажимать.
- **🎹 Свободно** — тюнер: показывает, какую ноту ты играешь и насколько точно.

Играть можно на настоящем пианино (через микрофон), на экранных клавишах, на клавиатуре компьютера (`A W S E D F T G Y H U J K`, `Z`/`X` — октава, `Пробел` — пауза) или на MIDI-клавиатуре.

## Свои песни (Undertale, Minecraft и любые другие)

Мелодии из игр защищены авторским правом, поэтому в репозитории их нет. Добавь свои:

1. Найди MIDI-файл нужной мелодии.
2. Нажми «＋» в разделе Undertale или Minecraft (или «Загрузить MIDI»), либо перетащи файл на страницу.
3. Выбери дорожку с мелодией — приложение превратит её в урок.

Песни хранятся в браузере (localStorage). Ноты можно записать и вручную: `C4 D4 E4:2 R C4+E4+G4:2` (`:2` — две доли, `R` — пауза, `+` — аккорд).

## Запуск

Микрофон работает только по `https://` или `localhost`, поэтому открывай через GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root) или локально: `python3 -m http.server`.

## Настройки микрофона

В ⚙️ есть ползунок чувствительности со шкалой громкости. Если на пианино разные октавы определяются неверно, оставь включённым «Засчитывать ноту в любой октаве».
